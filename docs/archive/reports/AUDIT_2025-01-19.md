## Context Clarification

These three repositories are **independent products** from the same developer (Mustard Seed Networks):

| Repo | Purpose |
|------|---------|
| **Seed** | Network diagnostic appliance (plug-in analyzer) |
| **Stem** | Network performance testing (RFC 2544/Y.1564) |
| **NIAC** | Network device simulator |

**"Architecture" in this context means:** Layout consistency, developer style, structural patterns - NOT code sharing or layered dependencies.

## 1. Executive Summary

### Overall Maturity Score: 4/10

Good tooling choices (Biome, golangci-lint), but inconsistent execution across repos that should share style/structure conventions.

### Top 5 Issues (Revised)

1. **STYLE INCONSISTENCY** - Same developer, but repos don't follow consistent patterns
2. **DOCUMENTATION SPRAWL** - Docs scattered, some stale, unclear what belongs where
3. **NAMING INCONSISTENCY** - `web` vs `ui`, package names differ, doc naming conventions differ
4. **INFRASTRUCTURE DRIFT** - Makefile structures differ, some have deprecated Makefile.common
5. **DIRECTORY DRIFT** - Similar directories named differently (`deb/` vs `debian/`)

## 4. Recommended Standards

### 4.1 Directory Naming (Canonical)

```
{product}/
├── cmd/{binary}/
├── configs/
├── deploy/
│   ├── deb/                   # NOT debian/
│   ├── rpm/
│   ├── systemd/
│   └── kubernetes/            # If applicable
├── docs/
├── internal/
├── mk/
│   ├── build.mk
│   ├── deps.mk
│   ├── lint.mk
│   ├── package.mk             # If packaging
│   ├── security.mk
│   └── test.mk
├── scripts/
├── tests/
│   ├── integration/
│   ├── load/
│   └── smoke/
├── ui/                        # Standard name for web UI
│   └── src/
│       ├── api/
│       ├── components/
│       ├── contexts/
│       ├── hooks/
│       ├── stores/
│       ├── styles/
│       ├── test/
│       ├── types/
│       └── utils/
├── _project_specs/
├── .claude/
├── Makefile                   # NO Makefile.common
└── ...
```

### 4.2 Package Naming

**Decision Needed:** Pick one pattern:
- Option A: `{product}-ui` (seed-ui, stem-ui, niac-ui)
- Option B: `{product}-web` (seed-web, stem-web, niac-web)
- Option C: `@msn/{product}-ui` (scoped)

### 4.3 Document Naming

| Type | Convention |
|------|------------|
| Standard docs | SCREAMING_SNAKE.md |
| Config files | kebab-case.yaml |
| Scripts | kebab-case.sh |
